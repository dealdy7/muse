🚀 QUICK START GUIDE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Start the CLI:
   $ npm start

2. Select "Run Automations" from the main menu

3. Choose "OpenRouter API Key (Add to 9Router)" from the automation list

4. Enter your OpenRouter API Key when prompted
   (Format: sk-or-xxxxx)

5. Choose proxy settings if available

6. Automation will:
   • Launch browser
   • Navigate to 9Router
   • Add your API key
   • Verify & rename connections
   • Complete processing

7. Review results and optional retry failed accounts
